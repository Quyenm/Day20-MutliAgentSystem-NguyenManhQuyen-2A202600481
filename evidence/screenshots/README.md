Put all submission screenshots in this folder.

Use JPG files and keep this naming order:

1. `01-localhost-overview.jpg`
   - Localhost web demo at `http://127.0.0.1:8000`
   - Show query input, controls, and metric cards.

2. `02-localhost-baseline-vs-multi-agent.jpg`
   - Show baseline answer and multi-agent answer side by side.

3. `03-localhost-flow-graph-tools.jpg`
   - Show baseline flow, multi-agent flow, and tool calls.

4. `04-localhost-sources-report.jpg`
   - Show sources, benchmark/report preview, and artifact/Langfuse links.

5. `05-langfuse-trace-list.jpg`
   - Show latest rows for `baseline benchmark`, `multi-agent benchmark`,
     `researcher`, `analyst`, and `writer`.

6. `06-langfuse-multi-agent-trace-detail.jpg`
   - Show input, output, route metadata, source count, and trace event count.

7. `07-langfuse-baseline-trace-detail.jpg`
   - Show input, output, and empty baseline route history.

8. `08-benchmark-report.jpg`
   - Show `reports/benchmark_report.md` with baseline and multi-agent rows plus
     Agent Trace Summary.
